huff

native engine · milestone 08 · 2026

Huff is being migrated to a native Rust + wgpu media engine. The existing control surface is preserved while playback, timing, GPU rendering, and output move out of the WebView.

Milestone 08: the native media and effect pipeline now publishes its authoritative render-resolution output directly to Syphon on macOS and Spout on Windows through bounded latest-frame bridges. Recording, export, and final parameter calibration remain.

Syphon.framework is bundled — no install required.
The framework ships inside this project at src-tauri/frameworks/Syphon.framework and is embedded in the .app at build time.

Huff reads the authoritative native wgpu output through a bounded triple-buffer bridge, then publishes it through a persistent Metal texture.
The source appears as "huff" in Syphon clients such as Resolume, VDMX, MadMapper, CoGe, and Millumin.

Windows only. Huff reads the authoritative native wgpu result through a bounded triple-buffer bridge and uploads the newest complete RGBA frame to SpoutDX.
The source appears as "huff" in Resolume Avenue, MadMapper, Spout for OBS, and other Spout receivers.
