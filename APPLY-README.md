# Apply HUFF Native Milestone 17

The changed-files archive is intended for a clean Milestone 16 tree. Copy it over the project root while preserving directory structure.

Milestone 17 changes the native MIDI/OSC modules, application startup wiring, renderer input/action handling, Tauri commands, mapping UI, version metadata, and project documentation. It also adds `control_mapping.rs`, `CONTROL-MAPPING.md`, and two example map files.

The complete archive is safer when the Milestone 16 tree contains local changes or when file deletions/renames are uncertain.
