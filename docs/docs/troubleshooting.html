INTEGRATED SUPPORT0.21.0 / HNW-21

Use symptoms to identify which subsystem owns the failure. Production Verification and exported diagnostics should be the first tools, not a blind reset of the entire application.

ON THIS PAGE

Video transport runs but image is frozen

  1. Open VERIFY and inspect decoder progress, watchdog recoveries, surface health, and frame progression.
  2. Try Restart Source.
  3. If the decoder advances but the surface does not, try Recover Surface.
  4. Export diagnostics before restarting the application if the condition persists.

Glitch or Flow stops responding

  1. Confirm the feature is still enabled and Program is not set to Clean.
  2. Inspect Monitor=Field Store to determine whether persistent state is advancing.
  3. Use Clear Buffers to reset temporal pixels without resetting all parameters.
  4. Inspect route plan and Flow target.
  5. Check GPU/readback health in VERIFY.

Audio stops

  1. Check selected audio source and device state.
  2. Inspect underflows and video-audio progress in VERIFY.
  3. Restart Source; avoid changing ownership during recording/export.
  4. Test the same file with Silent output to isolate video from audio failure.

Syphon/Spout receiver sees nothing

  1. Confirm Program is the intended bus.
  2. Confirm sender is Active and frame count advances.
  3. Restart Outputs.
  4. On Windows, refresh/select the correct adapter and verify receiver compatibility.
  5. Use a lower sender FPS to reduce bridge pressure.

Offline export fails

  1. Run production validation and confirm the requested encoder exists.
  2. Start with Native resolution, H.264, short duration, static state, silent audio.
  3. Add source audio, automation, high resolution, alpha, or image sequence one at a time.
  4. Inspect failed/cancelled manifests and temporary outputs.
  5. Verify disk space and destination permissions.

8K or high-resolution export is rejected

The graph estimate may exceed the current bounded resource limit or the GPU’s texture/memory limits. Lower export resolution, history resolution, history depth/capture rate, or choose a performance history preset.

Queue shows interrupted/stuck work

After a crash, unfinished jobs are marked Interrupted and dispatch pauses. Inspect the destination and manifests, then retry from frame zero or clear the job. Do not assume a partial file is complete.

Camera unavailable

Check OS permission, refresh devices, try a supported format/profile, and read the camera section in VERIFY. Camera behavior is one of the most device-specific parts of the system.

Last resort

Use Recover All, export diagnostics, then restart the application. Preserve the diagnostics folder and reproduction steps before resetting projects or deleting state files.

Do not use Reset as a universal fix. Reset changes parameter values and can erase the evidence needed to understand a pipeline or state problem. Prefer targeted recovery first.
