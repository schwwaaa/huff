# HUFF Native wgpu Documentation Archive

This static site updates the supplied HUFF documentation for the completed `0.21.0 / HNW-21` native wgpu architecture.

Open `index.html` in a browser. `docs.html` contains all documentation in one printable/searchable file.

## Preservation structure

- `docs/` — current comprehensive feature documentation
- `media/` — architecture, routing, state, output, and development diagrams
- `reference/` — raw authoritative milestone/design/testing notes
- `archive/original-docs/` — the exact incoming documentation snapshot

The site distinguishes integrated, provisional, and research-only systems and records removal/retention guidance for future production pruning.
