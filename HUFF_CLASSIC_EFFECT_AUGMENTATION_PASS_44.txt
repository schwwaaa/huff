HUFF CLASSIC EFFECT AUGMENTATION PASS 44
SOLARIZE ACTIVE-PARAMETER UI + LUMA/GLOBAL-MIX PERFORMANCE REPAIR

Baseline
--------
HUFF Classic Pass 43 — Solarize Fluidity, itself built on the runtime-accepted
Pass 41A Classic baseline and the positively received Pass 42/43 Solarize work.
Legacy Tauri v1 + p5.js / Canvas2D only.

Purpose
-------
1. Make Solarize mode ownership obvious by showing only controls that apply to
   the selected Solarize algorithm.
2. Reduce the FPS hit observed when Solarize runs with Pipeline Luma Key and
   Global Mix, without slowing source playback and without processing Solarize
   only every Nth frame.

UI change
---------
Shared controls always visible:
  ON / MODE / AMOUNT / FLUIDITY

THRESHOLD mode shows:
  THRESH / SOL R / SOL G / SOL B

LUMA QUANTIZE mode shows:
  LEVEL / SOFT / INVERT

Inactive controls remain in canonical state/presets/MIDI/OSC, but are hidden in
this performance surface and disabled until their mode is selected.

Performance repair
------------------
A) Solarize temporal cadence
The older adaptive overload guard that reused a processed Solarize image on
2nd/3rd render frames is removed. Solarize now processes every render call.
Pass 43 FLUIDITY remains continuous temporal slew, not sample/hold.

B) LIVE COMPOSITE Luma fast path
Pipeline Luma Key already performs one bounded source getImageData() to extract
luminance. Pass 44 retains that ImageData and writes the shaped matte directly
into its alpha bytes, preserving source alpha. This removes the former second
640px source copy, separate mask upload, and destination-in draw for LIVE /
COMPOSITE keying. STENCIL keeps the accepted fallback path.

C) Safe Global Mix + Solarize fusion
When Solarize is active and there is no active transform between the selected
Global Mix position and Solarize, Global Mix is deferred into Solarize's existing
max-640px scratch before its one required readback. This avoids a redundant
full-resolution Global Mix draw immediately before that synchronous readback.
No stage is fused across Feedback, Flow, or Symmetry; FINAL Global Mix remains
strictly after Solarize.

Protected
---------
- THRESHOLD pixel transform helpers unchanged.
- LUMA QUANTIZE pixel transform helpers unchanged.
- FLUIDITY transfer/presentation helpers unchanged.
- Feedback/Persistence equations unchanged.
- Flow byte-for-byte unchanged/frozen.
- Pipeline runtime and recipe order unchanged.
- Factory presets unchanged.
- Native Tauri runtime unchanged.
- No new full-resolution image buffer.
- Solarize remains one bounded getImageData + one bounded putImageData per
  processed render call.
