HUFF Classic Optimization Pass 5
================================

Scope
-----
Render hot-path and pixel-processing optimization. No new effects, controls, or
routing behavior were added. This pass includes all Pass 4 Syphon work.

Changes
-------
- Full-frame canvas replacements use Canvas2D `copy` compositing instead of a
  separate clearRect plus drawImage pass.
- The decoded-frame serial now advances independently of history capture.
- Flow Warp computes and draws each tile in one grid traversal and no longer
  stores a full displacement field in typed arrays.
- Solarize reuses luma contribution tables and cached channel-output lookup
  tables, removing repeated per-pixel multiplications.
- Pipeline Luma Key rebuilds its CPU pixel mask only when a new decoded frame,
  threshold, invert state, or render size requires it.
- Feedback snapshots use a single full-surface copy operation.

Expected effect
---------------
Lower main-thread memory bandwidth, fewer CPU pixel operations, and less render
contention with the bounded Syphon stream path.

Behavioral boundary
-------------------
HUFF Classic remains Tauri v1 + p5.js/Canvas2D. Syphon remains a browser-canvas
readback followed by a native Metal upload; this pass reduces competing render
work but does not claim zero-copy output.
