Real-world scenarios

What people
do with huff

From club stages to gallery walls to bedroom studios — here's how huff fits into a working creative practice.

01
Performance

Live VJ sets

huff is built for the stage. Every parameter is live-mappable to a physical MIDI controller — no menu diving, no mouse. Map a fader to CORRUPT%, a knob to FEEDBACK ZOOM, a button to reseed the glitch engine. The performance becomes physical.

Syphon on macOS and Spout on Windows send the output directly into Resolume, VDMX, or MadMapper without a capture card or OBS. What huff renders is what the LED wall receives — at frame rate, with zero encoding lag.

01 Load a video loop or connect a camera to a capture card
02 Load a MIDI map for your controller — nanoKONTROL2 included
03 Enable Syphon / Spout → huff appears as a source in Resolume
04 Play. Turn knobs. The crowd doesn't know what's coming next — neither do you.
02
Post-production

Experimental film

huff treats footage as material, not content. Feed found video, archival footage, or your own work through the effect chain. Each run produces something different — the same source file with the same preset creates a different artefact on every pass because cluster physics and noise fields evolve from random seeds.

Record the canvas window with OBS for clean, chrome-free capture at any resolution. Build sequences by recording multiple passes, then edit in your NLE. The variations are infinite and non-reproducible — each take is unique.

01 Load source footage — found film, archival video, your own material
02 Build a preset — dial in the character you want
03 OBS window capture → record 5 takes — each will differ
04 Edit in Premiere / Final Cut / DaVinci — the glitch is baked into the file
03
Gallery / installation

Autonomous installation

Load a preset and leave. The cluster physics engine simulates momentum, inertia, and drift — glitch centres orbit and evolve continuously from a fixed starting state. Combined with feedback and flow warp, a single video loop produces hours of non-repeating imagery.

No timeline. No automation required. The randomness is seeded by the frame count — the same visual character but never the same exact moment twice. The installation runs until you switch it off.

01 Load a looping video or set camera to loop
02 Enable Clusters with SPEED > 0 — centres drift autonomously
03 Add Feedback with a slow zoom — the image slowly dissolves
04 Output canvas window to projector — press F for fullscreen, walk away
04
Live streaming

Interactive streaming

Wire your stream to huff via OSC. A Max/MSP or TouchDesigner patch can read Twitch chat commands, viewer votes, or audio levels and convert them to OSC messages on port 9000. The audience changes the visual in real time.

OBS window capture grabs the canvas window cleanly — no UI chrome, just the output. The Syphon / Spout path takes this further, feeding directly into an OBS virtual camera or an NDI distribution chain.

01 Set up a TouchDesigner or Max patch to read Twitch chat / audio RMS
02 Send OSC messages to 127.0.0.1:9000 → huff updates in real time
03 OBS window capture → encode → stream
04 Viewers see the visual change in response to what they type
