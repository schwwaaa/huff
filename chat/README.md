# HUFF Native Chat Freeze Archive

Open these files first:

1. `HUFF-NATIVE-CHAT-FREEZE-HANDOFF.md` — the complete handoff for the next testing chat.
2. `HUFF-MILESTONE-HISTORY-AND-INTEGRATION.md` — paragraph and plain-language explanation for every milestone.
3. `HUFF-CHANGELOG-INDEX.md` — index of all preserved raw upgrade notes.
4. `NEXT-CHAT-STARTER.md` — compact prompt to paste into the next chat.

The `changelogs/` directory preserves all available raw upgrade notes and authoritative support records. The `diagrams/` directory preserves the major development and architecture visuals.
