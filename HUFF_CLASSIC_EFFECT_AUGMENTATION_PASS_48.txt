HUFF CLASSIC — EFFECT AUGMENTATION PASS 48
==========================================

TITLE
Stable Layer Priority / Global Mix Curves / Expanded Luma Fades

BASELINE
HUFF Classic Pass 47 — LIVE Luma Performance.
Pass 47 was reported as working well enough to retain as the current keying foundation.

GOALS
1. Remove Layer Priority behaviors that do not behave like useful layer hierarchy.
2. Lightly extend Global Mix without adding a new routing graph, source, framebuffer, or expensive stage.
3. Expand the compositing/fade vocabulary of the Luma COMPOSITE target.

LAYER PRIORITY
Previous Classic choices:
- SCAN TOP
- CORRUPT TOP
- NEUTRAL / frame-alternating order
- PULSE / timed alternating order

Pass 48 choices:
- SCAN TOP
- CORRUPT TOP

The two retained choices are explicit stable paint order. Legacy neutral/pulse values are accepted during preset migration but normalize to SCAN TOP. The old oscillators are not hidden; their active runtime path and Pulse Speed state are removed.

GLOBAL MIX
Existing architecture remains:
clean source + current process image + Blend + Mix + Position.

New CURVE control:
- LINEAR: effective = Mix (exact compatibility default)
- SMOOTH: effective = Mix^2 * (3 - 2*Mix)
- PUNCH: effective = 1 - (1 - Mix)^2

The curve changes only control response. It does not add an image pass. The same effective amount is used by the ordinary Global Mix path and the existing bounded Solarize fusion path.

LUMA FADE
Original retained modes:
- X-FADE -> Canvas source-over
- SOFT ADD -> Canvas screen

Pass 48 extensions for TARGET=COMPOSITE:
- LIGHTEN
- DARKEN
- MULTIPLY
- OVERLAY
- HARD LIGHT
- DIFFERENCE

These modes operate after the key has already been extracted/shaped. They change the relationship between the keyed clean patch and current process image; they do not alter Clip/Gain/Cleanup/Density/Invert or LIVE/STENCIL matte generation.

REFERENCE BASIS
- Magic DaVE and VIXID use explicit stable layer hierarchy / top-layer concepts, supporting the removal of temporal order oscillation from a control named Layer Priority.
- Grass Valley INDIGO explicitly documents Luma-key Add and X-Fade modes; those two remain the historical/reference pair.
- VIXID demonstrates that blend relationship itself can be a compact live-performance parameter. The six additional Luma fades are HUFF Classic extensions, not claims of INDIGO emulation.

- Solarize THRESHOLD
- Solarize LUMA QUANTIZE
- Solarize FLUIDITY
